## 올바른 백테스트 방법론

### 적용된 규칙 (Look-Ahead Bias 방지)

```
1. Entry: 신호 발생 다음 봉 OPEN에서 진입 (같은 봉 close 아님)
2. TP/SL: HIGH/LOW로 감지 (close가 아닌 실제 도달 가격)
3. 같은 봉 청산 불가: bars_held >= 1 조건 필수
4. 잔고 기반 포지션 사이징: position = balance * pct * leverage
5. 수수료 포함: 0.05% × 2 (entry + exit)
6. 미실현 손익 기반 Drawdown 계산
```

### 이전 백테스트와의 차이

| 항목 | 잘못된 방법 | 올바른 방법 |
|------|------------|------------|
| Entry 시점 | 신호 발생 봉 Close | **다음 봉 Open** |
| TP/SL 감지 | Close 가격 비교 | **High/Low 도달 확인** |
| 같은 봉 청산 | 허용 | **불가** |
| 포지션 크기 | 고정 단위 | **잔고 기반** |
| 수수료 | 무시 | **양방향 0.05%** |

### 왜 0.5% 일일 수익률이 어려운가?

1. **수수료 부담**: 양방향 0.1%가 수익의 큰 부분 잠식
2. **슬리피지 미반영**: 실제 거래 시 추가 손실 예상
3. **마틴게일 한계**: 연속 손실 시 급격한 Drawdown 위험
4. **신호 품질**: 어떤 기술적 지표도 일관된 0.5%+ 수익 불가
5. **시장 효율성**: 단순 기술적 분석만으로는 초과 수익 어려움

### 현실적 기대치

```

- 최고 일일 수익률: +0.134%
```
