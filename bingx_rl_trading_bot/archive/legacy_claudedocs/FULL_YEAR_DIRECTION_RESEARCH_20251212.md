## 실전 적용 방안

### 레짐 판단 방법

실시간으로 레짐을 판단하려면:

```python
def detect_regime(df, lookback=20):
    """
    20일 가격 추세로 레짐 판단
    """
    close = df['close'].iloc[-1]
    close_20d_ago = df['close'].iloc[-lookback * 96]  # 20일 전

    pct_change = (close - close_20d_ago) / close_20d_ago * 100

    if pct_change > 5:
        return 1  # 상승장
    elif pct_change < -5:
        return -1  # 하락장
    else:
        return 0  # 횡보
```

### 진입 조건

```python
# LONG (상승장에서만)
if regime == 1:
    if rsi_prev < 30 and rsi_curr > rsi_prev:
        enter_long()

# SHORT (하락장에서만)
if regime == -1:
    if rsi_prev > 70 and rsi_curr < rsi_prev:
        enter_short()
```

### 청산 조건

- **SL**: 진입가 대비 -1.5%
