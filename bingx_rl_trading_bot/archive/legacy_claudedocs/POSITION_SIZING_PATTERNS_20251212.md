# 포지션 사이징 패턴 비교 분석 (2025-12-12)

## 연구 목적
D3+MP2 (Depth>=3, MaxPos=2) 전략을 마틴게일 스타일로 변환하여 최적의 포지션 사이징 비율 탐색

---

## 1. 테스트한 패턴 목록

### MP1 (단일 포지션)
- `MP1 (4x)`: 단일 4x 레버리지

### MP2 (2개 포지션, 총 4x)
- `MP2 동일 (2:2)`: 균등 분배
- `MP2 역피라미드 (3:1)`: 첫 포지션 무겁게
- `MP2 피라미드 (1:3)`: 두번째 포지션 무겁게

### MP3 (3개 포지션, 총 4x)
- `MP3 동일 (1.33:1.33:1.33)`: 균등 분배
- `MP3 역피라미드 (2:1.5:0.5)`: 첫 포지션 무겁게
- `MP3 피라미드 (0.5:1.5:2)`: 마지막 포지션 무겁게

### MP4 (4개 포지션, 총 4x)
- `MP4 동일 (1:1:1:1)`: 균등 분배
- `MP4 마틴게일 (1:2:4:8)`: 후반 포지션 무겁게 (전통적 마틴게일)
- `MP4 역마틴 (8:4:2:1)`: 첫 포지션 무겁게 (역마틴게일)
- `MP4 피라미드 (1:2:2:1)`: 중간 무겁게
- `MP4 프론트 (4:2:1:1)`: 첫 포지션 무겁게
- `MP4 백로드 (1:1:2:4)`: 후반 무겁게
- `MP4 탑헤비 (3:1:1:1)`: 첫 포지션 매우 무겁게
- `MP4 밸런스 (2:2:1:1)`: 앞쪽 무겁게

## 3. 핵심 발견: 마틴게일 vs 역마틴게일

### 포지션별 성과 분석 (전체 데이터)

#### MP4 마틴게일 (1:2:4:8) - 최악의 패턴
```
#1 (1/15, 0.27x): 28거래, +3.3%, WR 43%   ← 낮은 레버리지, 높은 WR
#2 (2/15, 0.53x): 22거래, +6.7%, WR 45%
#3 (4/15, 1.07x): 18거래, +4.9%, WR 39%
#4 (8/15, 2.13x): 11거래, -5.5%, WR 27%   ← 높은 레버리지, 낮은 WR (손실!)
```

#### MP4 역마틴 (8:4:2:1) - 훨씬 효과적
```
#1 (8/15, 2.13x): 28거래, +26.3%, WR 43%  ← 높은 레버리지, 높은 WR
#2 (4/15, 1.07x): 22거래, +13.3%, WR 45%
#3 (2/15, 0.53x): 18거래, +2.5%, WR 39%
#4 (1/15, 0.27x): 11거래, -0.7%, WR 27%   ← 낮은 레버리지, 낮은 WR
```

#### MP4 동일 (1:1:1:1) - 비교 기준
```
#1 (1/4, 1.00x): 28거래, +12.3%, WR 43%
#2 (1/4, 1.00x): 22거래, +12.5%, WR 45%
#3 (1/4, 1.00x): 18거래, +4.6%, WR 39%
#4 (1/4, 1.00x): 11거래, -2.6%, WR 27%
```

### 결론

| 포지션 # | WR | 품질 | 최적 레버리지 |
|----------|-----|------|--------------|
| 1 | 43% | 높음 | **높게** |
| 2 | 45% | 높음 | **높게** |
| 3 | 39% | 보통 | 보통 |
| 4 | 27% | 낮음 | **낮게** |

**핵심 인사이트**: Depth>=3 필터 이후 첫 번째 진입의 품질이 가장 높음
- 마틴게일은 품질이 낮은 후반 포지션에 높은 레버리지 → 비효율적
- 역마틴게일/프론트로드는 품질이 높은 초반 포지션에 높은 레버리지 → 효과적

## 4. 최적 패턴: MP2 피라미드 (1:3)

### 왜 MP2 피라미드가 최적인가?

1. **MDD 최소화**: 1.5% (모든 패턴 중 최저)
2. **Combined RA 최고**: 14.96
3. **단순성**: 2개 포지션만 관리

### 동작 방식
```
Position #1: 1/(1+3) * 4x = 1.0x 레버리지
Position #2: 3/(1+3) * 4x = 3.0x 레버리지
```

**로직**:
- 첫 번째 포지션으로 시그널 테스트 (1x)
- RSI가 더 깊은 과매도/과매수로 진입하면 두 번째 포지션 (3x)
- 두 번째 포지션은 더 극단적인 가격에서 진입 → 반등 확률 높음

## 5. TP/SL 최적화 결과

상위 3개 패턴에 대해 TP/SL 최적화 수행:

| 패턴 | 기본 RA (SL 1.4%) | 최적화 RA (SL 1.6%) | 향상 |
|------|-------------------|---------------------|------|
| MP2 피라미드 | 14.96 | **54.20** | +262% |
| MP3 동일 | 9.87 | **127.80** | +1195% |
| MP4 밸런스 | 8.92 | **118.60** | +1230% |

**SL 1.6% 공통 적용 시**:
- MDD가 0.3~0.8%로 대폭 감소
- WR이 90%+ 달성
- Risk-Adjusted Return 폭발적 증가
