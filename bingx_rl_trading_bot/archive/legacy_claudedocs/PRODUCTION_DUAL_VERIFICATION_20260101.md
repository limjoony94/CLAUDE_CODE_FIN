## 검증 방법론

### Type 1: Signal Quality (신호 품질)
- **방법**: 모든 신호 발생 시점에서 Entry (포지션 상태 무시)
- **Entry**: 신호 발생 다음 봉 Open
- **Exit**: High/Low로 TP/SL 체크
- **통과 기준**:
  - 승률(WR) ≥ 50%
  - 기대값(EV) > 0

### Type 2: Actual Trading (실제 거래)
- **방법**: 실제 거래 시뮬레이션 (포지션 있으면 진입 불가)
- **Entry**: 포지션 없을 때만 진입
- **Exit**: TP/SL 도달 시 청산
- **통과 기준**:
  - Total PnL > $0
  - Walk-Forward 일관성 ≥ 50%

## 🔴 긴급 권고사항

### 즉시 조치 필요

1. **모든 프로덕션 봇 운영 재검토**
   - 4개 봇 모두 이중 검증 실패
   - 특히 LONG 방향 성과가 전반적으로 매우 나쁨

2. **RSI Trend Filter & TrendFilter MACD: LONG 진입 중단 검토**
   - RSI: LONG WR 0%
   - MACD 1H: LONG WR 12.5%
   - SHORT만 운영하거나 LONG 로직 전면 재설계 필요

3. **Engulf 5m: R:R 비율 수정**
   - 현재 TP 1.2% / SL 1.5% = 0.8 R:R (불리)
   - TP 2.0% / SL 1.5% 또는 TP 1.8% / SL 1.2%로 조정 검토

4. **SuperTrend 5m: 기본 신호 품질 개선 필요**
   - 신호 자체가 예측력 부족 (WR 41%, EV -0.15%)
   - ADX 필터 등 추가 필터 검토

### 검증 한계 및 주의사항

| 항목 | 이 검증에서 | 프로덕션에서 |
|------|------------|-------------|
| RSI Exit | Fixed TP/SL | BE+Trail+Spike |
| SuperTrend TP/SL | Fixed Base | Vol-Adaptive |
| SuperTrend Exit | Full TP | Scale-out 3단계 |
| 복리 효과 | 반영됨 | 동일 |
| 수수료 | 반영됨 | 동일 |

**따라서**:
- 프로덕션 봇이 고급 Exit 로직을 사용하므로, 실제 성과가 다를 수 있음
- 그러나 **신호 품질(Type 1)이 낮으면** 고급 Exit도 한계가 있음
- RSI LONG WR 0%, MACD LONG WR 12.5%는 Exit 로직으로 극복하기 어려움
