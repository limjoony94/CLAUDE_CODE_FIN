# 전략 신호 품질 감사 보고서 (2025-12-29)

## 개요

운영 중인 3개 봇의 신호 품질을 통계적으로 검증한 결과, **모든 전략이 랜덤 진입과 통계적 차이가 없음**이 확인됨.

## 검증 방법론

### 사용 데이터
- **기간**: 2025-11-23 ~ 2025-12-23 (30일)
- **타임프레임**: 5분봉
- **데이터 소스**: `data/btc_5m_30days_temp.csv` (8,640 rows)

### 통계 검증
1. **Bootstrap 95% 신뢰구간**: 1,000회 리샘플링
2. **랜덤 비교**: 500회 시뮬레이션, 동일 Exit 로직 적용
3. **p-value**: 실제 평균 수익률이 랜덤보다 높을 확률

### 유의성 기준
- 95% CI가 0을 포함하지 않아야 함
- p-value < 0.05
