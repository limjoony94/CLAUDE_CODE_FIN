## 2. 테스트된 메커니즘

### 2.1 고정 TP/SL (베이스라인)
```python
TP = entry_price ± 2.0%
SL = entry_price ∓ 1.5%
```

### 2.2 ATR Dynamic TP/SL
```python
TP = entry_price ± (ATR × tp_atr_mult)
SL = entry_price ∓ (ATR × sl_atr_mult)
# tp_atr_mult: 1.5, 2.0, 2.5, 3.0, 3.5, 4.0
# sl_atr_mult: 0.75, 1.0, 1.25, 1.5, 2.0
```

### 2.3 SuperTrend Trailing Stop
```python
TP = entry_price ± (ATR × tp_atr_mult)
SL = SuperTrend Line (동적 추적)
# tp_atr_mult: 1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 5.0
```

### 2.4 Hybrid BE + Trail
```python
초기_SL = entry_price ∓ (ATR × sl_atr_mult)
BE_Trigger = be_trigger%
BE 활성화 후 → SL = SuperTrend Line
# tp_atr_mult: 2.0, 2.5, 3.0, 3.5, 4.0
# sl_atr_mult: 1.0, 1.25, 1.5, 2.0
# be_trigger: 0.5%, 1.0%, 1.5%
```
