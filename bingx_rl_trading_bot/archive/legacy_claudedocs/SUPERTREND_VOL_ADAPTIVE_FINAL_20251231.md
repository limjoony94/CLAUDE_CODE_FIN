## 2. Vol-Adaptive 메커니즘 설명

### 2.1 핵심 로직
```python
# ATR 백분위수 계산
vol_pct = (current_atr - min_atr) / (max_atr - min_atr)

# 변동성 배수 결정
if vol_pct > 0.8:
    vol_mult = 1.5   # 고변동성 → TP/SL 확대
elif vol_pct > 0.5:
    vol_mult = 1.2   # 중변동성
elif vol_pct > 0.2:
    vol_mult = 1.0   # 저-중변동성
else:
    vol_mult = 0.7   # 저변동성 → TP/SL 축소

# 동적 TP/SL 적용
tp_pct = base_tp * vol_mult
sl_pct = base_sl * vol_mult
```

### 2.2 장점
- 고변동성: TP/SL 확대 → 조기 청산 방지, 수익 극대화
- 저변동성: TP/SL 축소 → 현실적 목표, 빠른 익절
