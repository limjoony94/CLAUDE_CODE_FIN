## Selection Methodology

### 1. Pattern Discovery
- **Source**: `unified_pattern_discovery.py`
- **Data**: 270일 (77,760 bars)
- **Classification**: Ground Truth (12-type)

### 2. Multi-Criteria Filtering (Moderate-B)
```
MC < 0.02       (Monte Carlo p-value)
WF >= 4/5       (Walk-Forward score)
WR >= 55% (L)   (Win Rate threshold)
WR >= 50% (S)
Trades >= 40    (Sample size)
```

### 3. Deep Analysis Scoring
```python
quality_score = WR × (1 - MC) × (WF / 5)
risk_adj_score = PnL / (1 + MDD)
stability_score = monthly_consistency × (1 - CV)
overall_score = (quality × risk_adj × stability) ** (1/3)
```
